# 添付HTMLの画面レビュー

## 総評

現在の画面は、機能そのものは多数実装されていますが、利用者が達成したい作業よりも、内部データ構造と管理機能が前面に出ています。

特に次の3画面は、レイアウト修正だけでなく導線の再設計が必要です。

1. シナリオ・テストケース一括編集
2. テスト実行
3. ユーザー管理

## 主な改善点

### シナリオ画面

- 「新規作成／既存編集」の切り替えと「読み込み」を廃止
- 左側で選択したシナリオを同じ編集表へ即時表示
- 「シナリオの手順」ではなく「確認項目一覧」
- 1行がケースなのか手順なのかを明確にする
- ケース詳細は別画面ではなく右サイドパネル
- 既存ケース追加、フォルダから作成、Excel貼り付けは「確認項目を追加」メニューへ集約
- データセットという用語を前面に出さず「テストデータ」と表示
- フォルダを左側のエクスプローラー型ツリーへ統合

### テスト実行画面

- 実行情報と結果入力を分離
- 左に確認項目一覧、右に現在の確認項目
- 1項目ずつ「保存して次へ」で進める
- 結果変更が初期値に戻る不具合を最優先修正
- 証跡欄でアップロード・貼り付け・進捗・エラーを完結
- 「サーバー内部でエラーが発生しました」だけで終わらせず、再試行方法とエラーIDを表示

### ユーザー管理

- ユーザー選択とプロジェクト選択を同じサイズの2カラムに統一
- ユーザーを先に選択
- プロジェクトを複数選択
- 割り当てと解除を明示的なボタンで実行
- 現在の割り当て状況をユーザー一覧に表示
