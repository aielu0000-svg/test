# UIドラフト

最終更新: 2026-04-23

## 基本方針

画面遷移を増やさず、手順一覧を主画面に置く。手順詳細はクリック時だけポップアップで表示する。常時表示する情報は時間入力と進捗確認に絞り、本文やコードは必要な時に開く。

## 主画面

### 上部バー

- Markdown 取込
- 保存
- 手順書名
- 日時表示切替
  - 予定日時
  - 実施日時
- 状態フィルタ
  - 全手順
  - 未実施
  - 実施中
  - 完了

### 手順一覧

行単位で `###` の手順を表示する。`#` と `##` はグルーピング見出しとして使う。

候補列。

| 列 | 内容 |
| --- | --- |
| No | `##` 配下で自動採番した番号 |
| グループ | `#` / `##` の所属 |
| 手順名 | `###` の見出し |
| 開始 | 切替中の予定開始または実施開始 |
| 終了 | 切替中の予定終了または実施終了 |
| 所要 | 予定表示では `HH:mm` 入力、実施表示では開始・終了から自動計算 |
| 状態 | 未実施、実施中、完了など |

検索欄と補足欄は設けない。

予定列と実施列は同時表示しない。draw.io の画面3イメージを参考に、切替ボタンで `予定日時` と `実施日時` を切り替える。

切替時の考え方。

- 列構成は `開始 / 終了 / 所要` のまま固定
- 見出しまたは切替ボタンの選択状態で、現在表示している日時種別を明確にする
- 入力値だけを予定値・実績値で切り替える
- 切替によって一覧の横幅が変わらないようにする

### 予定日時表示

保全で確認した「かかった時間」を入力し、最初の予定開始時刻または途中で変更した日時から予定開始・予定終了を自動展開する。

- 最初の予定開始時刻
- 各手順の予定所要時間
- 自動計算された予定開始
- 自動計算された予定終了
- 手順単位の予定日時手動調整

予定日時は本番計画用なので、最初の予定開始時刻または途中で変更した日時を基準に後続予定を積み上げる構成にする。独立した基準日時欄は設けない。

予定日時の再計算ルール。

- 最初の予定開始時刻を変えた場合、先頭から順に所要時間を積み上げる
- 途中の手順で日時を変更した場合、その手順以降だけを変更後の日時から積み上げ直す
- 変更位置より前の手順は維持する
- 手動調整した行は、後続予定を再計算するための途中基準点として扱う

### 実施日時表示

本番作業中に開始打刻・終了打刻を行う。

- 開始打刻
- 終了打刻
- 実績所要時間の自動計算
- 誤打刻時の手動修正
- 開始打刻・終了打刻ボタンは詳細ポップアップ内に置く
- 一覧の日時表示部分をクリックまたは入力状態にして、誤打刻や予定時刻を修正できるようにする

## 手順詳細ポップアップ

手順行クリックで表示する。

- 手順名
- 所属グループ
- Markdown 本文
- コードブロック
- コードコピー
- 閉じる
- Red Hat Docs のようなドキュメント表示に寄せる
  - 番号付き手順
  - セクション見出し
  - 濃色コードスニペット
  - 文字なしのコピーアイコンボタン
  - `bash` / `yaml` などのコード言語別の色
  - 長い作業でもポップアップ内スクロールで読める
- 見出しジャンプ用のサイドメニューは置かない

ポップアップは一覧の上に重ねる。閉じると一覧のスクロール位置や入力途中の値は維持する。

## 時刻入力

予定日時・実施日時はいずれもアプリ側で入力する。

入力補助。

- 予定開始
- 予定終了
- 予定所要時間
- 予定所要時間は `HH:mm` 形式で入力する
- 最初の予定開始時刻または途中で変更した日時からの予定自動展開
- 予定日時の手動調整
- 実施開始
- 実施終了
- 今開始
- 今終了
- 所要時間自動計算

未決。

- 内部形式は `YYYY-MM-DD HH:mm`
- 表示は `4/16 12:00` のような短縮形式
- 日跨ぎを扱える前提にする
- 秒を扱うか、分単位に丸めるか
- 所要時間は分単位で自動計算する案を第一候補にする

## 試作

- 画面試作用ファイル: `function_order/prototype.html`
- 単体HTMLなのでブラウザで直接開ける

- 長い作業表示の確認用に、スクロールが必要な手順を追加している
- Red Hat Docs のライト/ダーク配色を参考にしたダークモード切替を追加している

## Markdown 解釈

~~~md
# 大グループ

## 手順グループ

### 実作業手順

本文

```bash
command
```
~~~

`#` は画面上の大きな区切り、`##` は手順グループ、`###` は一覧の1行として扱う。
