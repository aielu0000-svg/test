Excel template presentation module

QuestionAnswer
What calls it?web/src/server/routes/excel.ts calls decorateCasesTemplate after buildCasesTemplate.
What does it affect?The downloaded official workbook presentation. The workbook remains 使い方/入力/共通データ, but the default input surface is now intentionally minimal: 入力 has exactly four columns (テスト名・確認項目名・操作・期待結果) with thin borders A1:D201, and 共通データ has exactly three columns (テスト名・項目名・値) with thin borders A1:C201. Actual examples remain in 入力 rows 2-3 and 共通データ row 2. Previous detailed friendly workbooks remain readable, so parser compatibility is preserved.
Which tests cover it?web/src/server/excelTemplatePresentation.test.ts verifies the exact four/three-column surfaces, borders, real examples and blank continuation cells. web/src/server/excelImport.test.ts verifies minimal parsing plus compatibility with the previous detailed friendly format and keyed legacy format. web/e2e/excel-import.spec.ts covers the complete download/import flow.
