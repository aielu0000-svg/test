Excel template modules

QuestionAnswer
What calls them?web/src/server/routes/excel.ts calls buildCasesTemplate, then decorateCasesTemplate for downloads; preview parsing calls parseCasesWorkbook.
What do they affect?The downloaded official workbook and Excel import parser. The workbook physically retains 使い方/入力/共通データ, but 使い方 is hidden. Visible 入力 restores the reference 8 columns: four blue required columns plus four orange optional columns, with priority list validation and thin borders A1:H201. Visible 共通データ restores the reference 6 columns with required/optional grouping and thin borders A1:F201. Real examples are in 入力 rows 2-3 and 共通データ row 2. Previous 4/3 minimal, 14/6 detailed-friendly and keyed workbooks remain readable.
Which tests cover them?web/src/server/excelImport.test.ts verifies the reference template and all supported compatibility formats. web/src/server/excelTemplatePresentation.test.ts verifies hidden guide, exact 8/6 columns, colors, dropdown, borders and real examples. web/e2e/excel-import.spec.ts covers the complete download/import flow.
